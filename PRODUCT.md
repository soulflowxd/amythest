# Product

## Platform

Adaptive: Chrome extension, native Windows companion, native Android app.

## Users

People who want to understand screen time and reduce time spent on chosen distractions.

## Product Purpose

Track activity locally, distinguish productive use from distracting use, and help users follow focus timers, daily limits and scheduled boundaries.

## Capabilities and Constraints

Chrome measures website activity and uses in-page reminders and per-video reason prompts. Windows measures desktop processes separately. Android measures app time with Usage Access; optional Accessibility sends foreground-app reminders, without closing apps or reading locked Private Space. Accounts and cross-device totals and limits use opt-in Convex sync. Local tracking requires no account. Hard Mode is a persistent commitment preference for focus timers, not tamper protection. Do not add sleep tracking or referral rewards.

## Brand Commitments

Amythest name, restrained amethyst mark, purple accent and original four-stage animated amethyst geode. Windows and Android now follow the supplied Opal screen hierarchy and flat dark visual direction. Windows uses top Home, Apps, Timer, Settings navigation. The user explicitly removed the previous Aero direction for these two apps. Chrome's current interface is outside this redesign.
